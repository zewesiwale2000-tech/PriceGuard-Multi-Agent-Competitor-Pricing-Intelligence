# Agent Spec: PriceGuard

## Overview
PriceGuard is an agentic monitoring system that tracks product prices online using search engine tools and drafts/delivers alerts or summary reports directly to a specified Slack channel. It utilizes a multi-agent or coordinated tool approach to keep users updated on price changes.

The system is designed with two core logical agents:
1. **AnalystAgent**: Responsible for performing price lookups and analysis using search APIs.
2. **DraftingAgent**: Responsible for formatting the final report/alerts and delivering them to Slack.

## Example Use Cases
### Track and Alert Price Drop
* **Input**: "Check the price of Google Pixel 9 Pro 128GB and alert me if it's below $900."
* **AnalystAgent Action**: Queries SerpAPI for "Google Pixel 9 Pro 128GB price", extracts current retail prices (e.g. $899 from a retailer), and compares it to the threshold.
* **DraftingAgent Action**: Formats a message: "🚨 Price Alert: Google Pixel 9 Pro 128GB is now available for $899 (below threshold $900)!" and sends it to the configured Slack Webhook.

## Tools Required
1. **Price Lookup Tool** (AnalystAgent):
   - **Purpose**: Search the web for current product pricing.
   - **API**: SerpAPI.
   - **Authentication**: `SERP_API_KEY`.
2. **Slack Delivery Tool** (DraftingAgent):
   - **Purpose**: Deliver alerts or reports to a designated Slack channel.
   - **API**: Slack Webhook.
   - **Authentication**: `SLACK_WEBHOOK_URL`.
3. **Gemini GenAI API**:
   - **Purpose**: Power the reasoning and execution of the agents.
   - **Authentication**: `GEMINI_API_KEY`.

## Constraints & Safety Rules
- Web search access must be restricted to price lookups via SerpAPI; arbitrary network requests are not allowed.
- Delivery must only target the authorized `SLACK_WEBHOOK_URL` (configured via env).
- Do not disclose or leak any API keys or configuration secrets in the messages or logs.

## Success Criteria
- The agent accurately searches and extracts pricing for a given query.
- The agent compares price points against thresholds correctly.
- The agent successfully formats and delivers notifications to the specified Slack webhook.
